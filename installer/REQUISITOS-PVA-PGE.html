Auditor Fiscal BITMAX 2.6.17

Requisito: Windows 64 bits. O instalador verifica essa condição antes de continuar.

O instalador contém o aplicativo e os componentes de execução empacotados nele. Não é necessário instalar Python ou Java para abrir o Auditor.

Validação oficial: para validar uma escrituração no PVA/PGE, instale o programa oficial da Receita Federal separadamente. O instalador BITMAX não redistribui esses programas; a Receita informa que o uso do software do Serpro é licenciado ao contribuinte para sua finalidade própria.

Downloads oficiais

  • EFD-Contribuições (PGE/PVA)
  • EFD ICMS/IPI (PVA)

Depois de instalar o PVA/PGE

Abra o Auditor, acesse Fontes oficiais e configure o caminho do programa validador instalado. A validação interna do Auditor pode ser usada sem o PVA; a validação oficial depende dele.

O instalador guarda o aplicativo na pasta do usuário. A desinstalação remove essa pasta e os atalhos, sem apagar os arquivos de escrituração que você selecionar no Auditor.
